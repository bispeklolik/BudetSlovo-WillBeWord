# Источник списка русских слов

`ru_50k.txt` — частотный список русских слов «FrequencyWords» (Hermit Dave), собранный
из субтитров OpenSubtitles 2018: https://github.com/hermitdave/FrequencyWords
(файл `content/2018/ru/ru_50k.txt`).

Лицензия содержимого — **CC BY-SA 4.0** (https://creativecommons.org/licenses/by-sa/4.0/).
Этот файл распространяется на тех же условиях. Код «Слова» остаётся под своей лицензией (MIT).

Изменения: 11.11.2026 удалены строки не на кириллице (1 271 строка: английские слова,
одиночные латинские буквы). Формат строки — `слово частота`.

Список используется для подбора вариантов неуверенного слова по звучанию.

# Слова психологии

`psy_terms.txt` — 2 443 формы около 300 слов психологии (тревожность, созависимость,
обесценивание, руминация, алекситимия, абьюз, проработать…), которых нет в `ru_50k.txt`.
Составлен для «Слова» 11.11.2026: четыре раздела (состояния, терапия, отношения и травма,
эмоции и тело), каждая форма проверена отдельно. Распространяется под лицензией «Слова» (MIT).
Формат тот же: `слово вес`, вес 1000 — выше редких слов из субтитров, ниже частых.
